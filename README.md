# 土地価格査定クン (tochi-satei-kun)

> 業者向け・完全無料の土地価格査定 AI エージェント
> A free Claude Skill for land price assessment in Japan

[![Claude Skill](https://img.shields.io/badge/Claude-Skill-orange)](https://docs.claude.com/skills)

## 概要

「土地価格査定クン」は、不動産業者向けに開発された**完全無料の土地価格査定 AI エージェント**です。物件住所を入力するだけで、公示地価・路線価・取引事例・用途地域等の根拠データを集約した査定レポートを自動生成します。

不動産鑑定士・松田幸一が開発する **クロードコワーカーシリーズ** の第二弾で、Anthropic 社の Claude Skill として実装されています。Claude 契約者であれば誰でも、追加費用なしで利用可能です。

## クロードコワーカーシリーズ

| ツール | 領域 | 状態 |
|---|---|---|
| [重調クン](https://github.com/signal-yield/jucho-kun) | 重要事項説明調査（35条書面） | 公開中 |
| 決済クン | 決済精算書自動生成 | 公開中 |
| **土地価格査定クン** | **土地価格査定** | **本リポジトリ・2026年5月公開予定** |
| DynamicDCFクン | 収益還元評価（モンテカルロDCF） | 構想中 |

## 特徴

- 🆓 **完全無料**（Claude 契約料金以外に追加費用なし）
- 🤖 **AI エージェントが自律実行**（対話で物件情報→査定書まで一気通貫）
- 📊 **査定根拠を明示**（公示地価・路線価・取引事例の出典付き）
- 📁 **xlsx 形式で出力**（そのまま社内資料・顧客提案書に流用可能）
- 🔓 **MIT License**（ユーザー自身による改変・社内カスタマイズ可）
