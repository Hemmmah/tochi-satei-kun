## 1. プロジェクト概要（30秒ピッチ）

**土地価格査定クン**は日本初の OSS（オープンソース）AVM。土地の査定価格を、ヘドニック回帰係数を **全開示** した「白箱方式」で出力する Claude Cowork スキル。

- 国内 AVM（HowMa, GA technologies, LIFULL）は全てクローズドソース
- 個人発 OSS が業界クローズド独占に挑戦する物語
- 「AVM 界の Linux」がメインタグライン

❌ **使わない**（顧客用シート同様、PR でも）: AI, 機械学習, 予測, 学習モデル（OLS は「機械学習」ではないため誤解を招く）

## 3. 訴求軸 3つ（PR Times 原稿の柱）

### 軸 1: 「OSS であること自体が革新」
- 国内 AVM はすべてクローズド → 日本初の OSS が空白を埋める
- GitHub に置いた瞬間、誰でもコードを読める＝鑑定士・媒介担当者が「なぜこの査定価格か」を完全に説明できる
- 「実装の難しさ」ではなく「公開する決断」が革新

### 軸 2: 「都度回帰の白箱方式」（vs ブラックボックスML）
- ヘドニック係数 β は **物件ごとに都度回帰**（固定値ではない、pre-trained モデルでもない）
- 全 12 特徴量の係数・p値・標準誤差・自由度調整済 R² を業者用シートに開示
- ブラックボックスの ML 系 AVM では原理的にできない透明性

### 軸 3: 「鑑定実務との接続」
- 不動産鑑定士（松田氏）が監修した鑑定書様式の比準表
- 業者用は鑑定書の「2行式」（事情補正/時点修正/標準化補正/地域格差）
- 顧客用は流推方式準拠の机上査定書
- 大手 AVM が SaaS で囲い込む領域に、OSS で開放を持ち込む

## 7. 必要な入力データ（PR Times にFAQ で載せる）

ユーザーが用意するもの:
1. **物件情報 JSON**（面積、所在、最寄駅、形状、接道、角地補正率など）
2. **MLIT 取引価格情報 CSV**（国交省「不動産取引価格情報検索」から DL、6年分推奨）
3. **地価公示 GeoJSON L01**（国土数値情報ダウンロードサイトから DL、東京都なら 50MB）

→ 「準備データ無料、ツール無料、誰でも今日から使える」が訴求。

**対象範囲**: 更地・所有権のみ。マンション・戸建・借地権・地上権は対象外。

## 12. リスクと事前対応（質問されたら）

| 質問 | 回答 |
|---|---|
| **マンションは？** | 対象外。建物評価が必要なため別ツールが適切 |
| **戸建は？** | 対象外。土地のみ |
| **借地権は？** | 対象外。所有権のみ |
| **精度は？** | adj R² で 0.45〜0.55 程度（世田谷区 6年データ）。鑑定評価書の代替ではなく、媒介査定の事前検討用 |
| **データはどこから？** | 国交省「不動産取引価格情報」+ 地価公示。両方とも公開データ |
| **業者の責任は？** | xlsx を顧客に渡した瞬間、業者が「自分の査定書」として endorse。ツール提供元の名前は文書に出ない（OEM 対応） |
| **収益モデルは？** | 本体無料・OSS。著者の鑑定本業の信頼性向上、講演・コンサル機会獲得が間接収益 |
| **海外展開は？** | 当面なし。日本の MLIT データ・地価公示に特化している |
